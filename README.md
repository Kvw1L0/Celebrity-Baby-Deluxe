# Celebrity Baby Deluxe

Experiencia interactiva de trivia visual para eventos: pantalla gigante, participantes y panel de administración sincronizados en tiempo real.

## Accesos

- Jugadores: `/`
- Administración: `/admin.html`
- Pantalla gigante: `/game.html`

Los cambios publicados en la rama `main` se despliegan automáticamente en Vercel.
